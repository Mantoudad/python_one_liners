Boolean and Keywords: and, or, not

The bool type in Python represents Boolean values, which can be either True or False. In python, Boolean and Integer data types are closely related, with True being equivalent to 1 and False being equivalent to 0. This means that you can perform arithmetic operations with Boolean values, and they will be treated as integers in those operations. For example, True + True will evaluate to 2, and False + True will evaluate to 1. This relationship allows for a seamless integration of Boolean logic with numerical computations in Python. The and, or, and not keywords are used to perform logical operations on Boolean values. The and operator returns True if both operands are True, the or operator returns True if at least one operand is True, and the not operator returns the opposite of the operand’s Boolean value.

x = 1 > 2  # Comparison operator, evaluates to False
print(x)  # Output: False

# Logical Operations
x, y = True, False
print(x and y)  # Logical AND
print(x or y)   # Logical OR
print(not x)    # Logical NOT

print((x or y) == True)
print((x and y) == False)
print((not x) == False)

The order of boolean operations in Python follows the standard precedence rules, which are as follows:
1. Parentheses ()
2. not
3. and
4. or
which means that not is evaluated before and, and and is evaluated before or. This order of operations ensures that logical expressions are evaluated correctly according to their intended meaning. For example, in the expression True or False and False, the and operation will be evaluated first, resulting in True or False, which then evaluates to True.

## Boolean Operations

Strings

Strings in Python are immutable sequences of characters and so they cannot be changed after they are created. They can be defined using single quotes ('...'), double quotes ("..."), or triple quotes ('''...''' or """..."""). Triple quotes are often used for multi-line strings. Python provides a wide range of string operations, including concatenation, slicing, and various string methods for manipulation and formatting.

## The string method

str(5) == 5 # is False
## Concatenation

The most frequently used whitespace characters in python are:
- the newline character \n, which represents a line break, - the space character \s, which represents a single space, - the tab character \t, which represents a horizontal tab. These whitespace characters are often used in string manipulation and formatting to control the layout and appearance of text. For example, you can use \n to create multi-line strings, \s to add spaces between words, and \t to align text in a tabular format.

The keyword “None”

The keyword None in Python represents the absence of a value. It’s similar to null in other programming languages. None is often used to indicate that a variable has no value or that a function does not return anything. It is important to note that None is a singleton object, which means that there is only one instance of None in the entire Python runtime. This allows for efficient memory usage and makes it easy to check for the presence of None using identity comparison (is None) rather than equality comparison (== None). None is the only value of the NoneType data type, and it is commonly used in various contexts, such as default function arguments, return values for functions that do not explicitly return anything, and as a placeholder for optional values.

def example_function():
    x = 5
    # This function does not return anything, so it implicitly returns None

print(example_function() is None)  # Output: True, the keyword `is` will be introduced next.
print("" == None) # is False, because an empty string is not equal to None.
print(0 == None) # is False, because None is not equal to any other value, including itself.

The keyword “is”

The keyword is in Python is used for checking whether two variables refer to the same object in memory. It is different from the == operator, which checks for value equality. When you use is, you are checking if both operands point to the same object, while == checks if the values of the operands are equal, regardless of whether they are the same object or not. For example, two different lists with the same contents will be considered equal with ==, but they will not be the same object in memory, so is will return False.

a = b = 3
print(a is b) # True

print([3] is [3]) # False, because they are different objects in memory

Reversing Lists

Reversing a list modifies the original list in place and does not create a new List object, which means it does not return anything.

lst = [1, 2, 3, 4, 5]
lst.reverse()
print(lst)  # Output: [5, 4, 3, 2, 1]
[5, 4, 3, 2, 1]

Sorting Lists

Sorting a list modifies the original list in place and does not create a new List object, which means it does not return anything. The result of the sorting operation is in ascending order by default, but you can specify the reverse=True argument to sort in descending order.

lst = [3, 1, 4, 1, 5]
lst.sort()
print(lst)  # Output: [1, 1, 3, 4, 5]
lst.sort(reverse=True)
print(lst)  # Output: [5, 4, 3, 1, 1]
[1, 1, 3, 4, 5]
[5, 4, 3, 1, 1]

Stacks

A stack is a data structure that follows the Last In, First Out (LIFO) principle. In Python, you can implement a stack using a list. The append() method is used to add elements to the top of the stack, and the pop() method is used to remove elements from the top of the stack.

stack = [5]
stack.append(10)  # Push 10 onto the stack, stack becomes [5, 10]
stack.append(15)  # Push 15 onto the stack, stack becomes [5, 10, 15]
stack.pop()  # Pop the top element (15) from the stack, stack becomes [5, 10]
stack.pop()  # Pop the top element (10) from the stack, stack becomes [5]
print(stack)  # Output: [5]
[5]

Queues

A queue is a data structure that follows the First In, First Out (FIFO) principle. In Python, you can implement a queue using a list, but it is more efficient to use the collections.deque class from the collections module, which provides an optimized way to append and pop elements from both ends of the queue.

from collections import deque
queue = deque([5])
queue.append(10)  # Enqueue 10, queue becomes deque([5, 10])
queue.append(15)  # Enqueue 15, queue becomes deque([5, 10, 15])
queue.popleft()  # Dequeue the front element (5), queue becomes deque([10, 15])
queue.popleft()  # Dequeue the front element (10), queue becomes deque([15])
print(queue)  # Output: deque([15])
deque([15])

Sets

A set is an unordered collection of unique elements. In Python, you can create a set using curly braces {} or the set() constructor. Sets are useful for performing mathematical operations like union, intersection, and difference.

s = {1, 2, 3, 4, 4}
print(s)  # Output: {1, 2, 3, 4}
{1, 2, 3, 4}

Collections of Sets

A set is a collection of unique elements. All data types in set must be hashable, which means all elements in a set must be immutable. Therefore, you cannot have a set of sets, because sets are mutable and cannot be hashed. However, you can have a set of frozensets, which are immutable and hashable.

name = "Alice"
print(hash(name))  # Output: A unique hash value for the string "Alice"

# Can we create a set of strings?
characters = {"Alice", "Bob", "Charlie"}
print(characters)  # Output: {'Alice', 'Bob', 'Charlie'}

# Can we create a set of lists?
try:
    list_set = { [1, 2], [3, 4] }  # This will raise a TypeError because lists are unhashable or mutable
except TypeError as e:
    print(e)  # Output: unhashable type: 'list'

Unordered Nature of Sets

Unlike lists, elements in a set do not have a specific order. Regardless of the order in which you add elements into a set, you can never be sure in which order the set will store them.

characters = {"Alice", "Bob", "Charlie"}
print(characters)  # Output: The order of elements may vary each time you run the code

Dictionaries

A dictionary is a collection of key-value pairs, where each key is unique and maps to a corresponding value. In Python, you can create a dictionary using curly braces {} with key-value pairs separated by colons :, or by using the dict() constructor.

calories = dict(breakfast=300, lunch=600, dinner=800)

calories["breakfast"] = 350  # Update the value for the key "breakfast"

Membership

Membership operators in and not in are used to check if a value is present in a sequence (like a list, tuple, or string) or a collection (like a set or dictionary). The in operator returns True if the value is found, while the not in operator returns True if the value is not found.

fruits = ["apple", "banana", "cherry"]
print("banana" in fruits)  # Output: True, checks if "banana" is in the list of fruits
print("grape" not in fruits)  # Output: True, checks if "grape" is not in the list of fruits
True
True

List and Set Comprehensions

List and set comprehensions are concise ways to create lists and sets in Python. They allow you to generate a new list or set by applying an expression to each item in an iterable, optionally filtering items using a condition.

# List Comprehension
squares = [x**2 for x in range(10)]
print(squares)  # Output: [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
# Set Comprehension
unique_squares = {x**2 for x in range(10) if x % 2 == 0}  # Only include squares of even numbers
print(unique_squares)  # Output: {0, 4, 16, 36, 64}
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
{0, 64, 4, 36, 16}

There are two fundamental ways of terminating a loop in Python: break and continue. The break statement is used to exit a loop prematurely when a certain condition is met, while the continue statement is used to skip the current iteration of the loop and move on to the next iteration.

Functions

Functions in Python are defined using the def keyword, followed by the function name and parentheses. Functions can take parameters, which are specified within the parentheses, and they can return a value using the return statement.

def greet(name):
    return f"Hello, {name}!"

print(greet("Alice"))  # Output: Hello, Alice!
Hello, Alice!

Lambdas

Lambda functions, also known as anonymous functions, are small, unnamed functions defined using the lambda keyword. They can take any number of arguments but can only have one expression. The expression is evaluated and returned when the lambda function is called.
lambda :
A lambda function can have one or multiple arguments, separated by commas. After the colon(:), you can write the return expression, which is evaluated and returned when the lambda function is called.

print((lambda x: x + 3)(5))  # Output: 8, this lambda function takes one argument x and returns x + 3
add = lambda x, y: x + y  # This lambda function takes two arguments x and y and returns their sum
print(add(2, 3))  # Output: 5
